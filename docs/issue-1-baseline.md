# Issue #1：确定实验基线与需求

> 说明：本文件内容用于在 GitHub 上创建 Issue，创建后关联后续开发分支与 PR。

## 背景

《开源软件与新技术》实验 01 要求以成熟开源博客为基线完成二次开发。需要在 Ghost 路线与 RealWorld 规范路线之间选择。

## 选择

- **选择路线**：Ghost（`TryGhost/Ghost`）。
- **固定版本**：Ghost `6.59.0` / Ghost CLI `1.32.3` / Node.js `22 LTS`。
- **负责人**：本人独立完成。

## 理由

Ghost 提供成熟的编辑器、标签、会员、评论与主题机制，可将时间集中在主题扩展与局部改造，避免重写认证、编辑器与存储。

## 风险

- 主题构建依赖 pnpm/gulp，需固定依赖版本。
- 本地 SQLite 数据与运行目录需通过 `.gitignore` 排除，避免误提交。

## 6 条验收场景

1. 前台 `http://localhost:2368/` 可访问。
2. 管理端 `http://localhost:2368/ghost/` 可访问并完成管理员初始化。
3. 管理员可发布并编辑带标签的文章。
4. 会员可注册/登录并对公开文章发表评论。
5. 关键词搜索可命中中文文章并跳转；无结果有提示。
6. 执行 `ghost stop` / `ghost start` 后文章与评论数据仍存在。
