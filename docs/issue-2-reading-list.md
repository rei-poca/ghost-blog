# Issue #2：自主功能 —— 稍后阅读（收藏）列表

> 说明：本文件内容用于在 GitHub 上创建 Issue，作为自主功能开发的验收依据。

## 用户故事

作为读者，我希望把感兴趣的文章收藏起来，稍后在一个列表里快速找到并继续阅读，而不必反复搜索。

## 数据来源

- 收藏数据仅存于浏览器 `localStorage`（键 `oss-blog-reading-list`），不调用后端，不涉及个人隐私上传。

## 界面入口

- 导航栏书签按钮（带计数 badge）打开「稍后阅读」抽屉。
- 文章卡片右上角、文章详情页标题下均提供收藏按钮。

## 失败状态 / 空状态

- 无收藏时抽屉显示「暂无收藏文章」空状态。
- 隐私模式或存储满时静默失败，不阻塞页面操作。

## 隐私影响

- 仅本地存储，无服务端传输，无第三方共享。

## 验收条件

- [ ] 点击卡片/详情页收藏按钮，图标进入「已收藏」态，计数 +1。
- [ ] 再次点击取消收藏，计数 -1，列表移除该项。
- [ ] 抽屉列表可跳转原文、可单条移除、可清空全部。
- [ ] 空状态正确显示；Esc 或点击遮罩可关闭抽屉。
- [ ] 刷新页面后收藏仍存在（localStorage 持久化）。

## 非目标（Non-goals）

- 不做服务端同步、多设备云同步。
- 不修改 Ghost 核心，不引入后端密钥。
